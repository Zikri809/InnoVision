# Easy2U — Manual Test Guide (step by step)

> No technical knowledge needed. One tester, one laptop, two browser windows.
> Just follow the steps in order and tick each box. If anything looks wrong,
> write down the step number (for example “5.3”) and what you saw — there is
> a sign-off sheet at the end.
>
> There are two paths: the **Quick check** (steps marked ★, about 45 minutes)
> and the **Full check** (everything, about 2 hours). Your lead will tell you
> which one to run.

## 0. Get ready (10 min, once)

**What you need**

- [ ] One laptop with a working camera. Use normal room lighting.
- [ ] A phone is handy (QR scan + one face-photo trick) but NOT required — every phone step has a no-phone alternative.
- [ ] A photo of any other person's face on your phone (a friend, family member — anyone who isn't you), or a printed face photo. Needed for step 5.2 only. If you have neither, step 5.2 has a fallback.

**Two browser windows — set this up first**

- [ ] Window A = LECTURER: your normal browser window. This stays logged in as the lecturer for the whole session.
- [ ] Window B = STUDENT: a private window — Chrome: press Ctrl+Shift+N (“New Incognito window”); Edge: press Ctrl+Shift+P (“New InPrivate window”). This stays logged in as the student.
- [ ] Tip: put them side by side (hold the Windows key and tap the arrow keys) and keep BOTH open the whole time. If you close Window B you will be logged out and must log in again (anything already saved is safe).
- [ ] When the browser asks, ALLOW camera access in Window B (the student needs the camera; the lecturer does not).

**Accounts — use the test accounts if you have them**

- [ ] If your lead gave you a lecturer login and a student login: log Window A in as lecturer, Window B as student. You are ready — skip to Rules.
- [ ] If you have NO accounts yet, create them now (takes 3 minutes). You need TWO different email addresses (for example your email plus a second one — Gmail trick: name+lecturer@gmail.com and name+student@gmail.com both reach the same inbox).
- [ ] Window A: tap **Register**, choose **Lecturer**, enter the **invite code** from your lead, tick the consent box, tap **Create account**. You should land on the Classes page.
- [ ] Window B: tap **Register**, choose **Student**, enter a **6-digit Student ID** (this can never be changed later, so type it carefully), tick the consent box, tap **Create account**. You should land on the Classes page.

**Rules — please read once**

- [ ] Do the steps IN ORDER from start to finish. Some steps cannot be undone (for example releasing results), and the order protects you.
- [ ] Only create AI quizzes when the guide says so — each one costs money.
- [ ] Never guess join codes. Too many wrong tries locks everyone out for 15 minutes.
- [ ] Notifications and emails in this test are REAL. That is expected.
- [ ] Name everything starting with **Test -** plus your name and today's date, for example **Test - Ali 27 Sep**. This keeps test data easy to spot.

## Phase 1 — Create a class and join it (10 min) ★

You play both parts: lecturer in Window A, student in Window B.

- [ ] 1.1 Window A: open **Classes**, tap **New Class** / **Create class**, name it **Test - \<your name> \<date>**, and open it. — You should see the new class in your list.
- [ ] 1.2 Window A: tap **Show QR**. — You should see a QR code, a join link, and a **Copy link** button. Tap **Copy link** — you should see “Link copied”.
- [ ] 1.3 Window B: paste the copied link into the address bar (OR scan the QR with your phone and log in there as the student). Tap **Join class**. — You should land on the student's Classes page WITH the new class. Open the link again — it should now say you are already enrolled (and NOT add a second copy).
- [ ] 1.4 Window B: tap the **bell** icon. — You should see a welcome message. Tap it — it should open the class. Tap **Mark all as read** — the red count should disappear.
- [ ] 1.5 Window A: create a second throwaway class called **Test - Archive**, then **Archive** it. Window B: refresh your Classes page. — The archived class should be GONE for the student but still visible to the lecturer. Now **Restore** it — it should come back for the student. (You may leave it archived to keep things tidy.)

## Phase 2 — Make two quizzes (lecturer, 15 min) ★

Window A only. Do NOT tap Publish until step 2.7.

- [ ] 2.1 Create a quiz called **Test - Exam**: type **Assessment**, turn hand gestures **ON**, time limit **15 minutes**. Add 4 questions by hand, one of each type: **Multiple choice**, **True / False**, **Multi-select** (tick several correct answers), and **Short answer** (write a short marking guide when asked). Attach a photo to one question. — All 4 questions should save and show in the list with the photo.
- [ ] 2.2 Tap **Import** and paste in 2 extra questions using the text format shown on screen. — A preview should appear first, then both questions should save.
- [ ] 2.3 Tap **Duplicate / Make a copy** on the Exam quiz. — A copy should appear as a new DRAFT with the same questions and photo.
- [ ] 2.4 Create a quiz called **Test - Practice**: type **Practice**, hand gestures **OFF**, no time limit, turn **ON** “Shuffle question & option order” if you see it. Tap **Generate with AI**: upload one scanned document (a photo of a page works), wait for the text to be read, tap **Generate**, wait for the progress steps, then EDIT one question and **Regenerate** one question. — Edited and regenerated questions should save; the other questions should be untouched.
- [ ] 2.5 Still in the AI window: start one more generation, then tap **Cancel** halfway. — Nothing new should be saved.
- [ ] 2.6 Delete the copy made in step 2.3. — It should disappear. (Quizzes that students already started can never be deleted — that block is correct, do not fight it.)
- [ ] 2.7 Tap **Publish** on BOTH quizzes. On the Practice quiz only, turn **ON** “Release results automatically”. — Both quizzes should show a **Live** tag, and Window B (student) should now show both in the quiz list.

## Phase 3 — Practice quiz and share links (student, 10 min) ★

Window B only. For the share-link check, Window A (lecturer) plays the part of the recipient — any logged-in user can open a shared quiz link.

- [ ] 3.1 Window B: start **Test - Practice**. Answer question 1, then **reload the page**. — The quiz should continue at question 2 (not restart, not get stuck). Finish all questions, then tap **Try again**. — A fresh attempt should start at question 1.
- [ ] 3.2 Window A: open the Practice results and tap **Release to students**. Window B: refresh your quiz list. — The Practice card should now have a **View results** button showing your score and the correct answers.
- [ ] 3.3 Window B: open **My Quizzes**, tap **New**, add one question, and tap **Share** to get a link. Copy it into Window A and play it to the end. — The last question should still show whether you were right, and you should reach the end screen.
- [ ] 3.4 Window B: tap **New code**, confirm. Open the OLD link again in Window A. — The old link should now show a plain “this link is not valid” page (NOT the quiz). Then tap **Unshare** and open the NEW link — it should show the same plain page.
- [ ] 3.5 If your lead asked for a share link for the automatic check: share one quiz again and SEND the new link to your lead. Do not unshare it.

## Phase 4 — Register your face (student window, 5 min) ★

Window B only (camera must be allowed there).

- [ ] 4.1 Open **Face setup** (from the menu). Tick the consent box FIRST. — The camera should only start AFTER you tick consent.
- [ ] 4.2 Follow the instructions: look **front**, then **left**, then **right**, and **blink** when asked. — You should see “Enrolled successfully”. Open the page again — it should remember you are enrolled.
- [ ] 4.3 Window A: open the class and check the student list. — Your enrollment should be visible, with NO photos of your face shown anywhere.

## Phase 5 — Sit the exam with the camera on (both windows, 20 min) ★

The exam runs in Window B with the camera ON. Keep Window A ready — you will switch to it (Alt+Tab) for the lecturer actions.

- [ ] 5.1 Window B: start **Test - Exam**. Tap **Begin**, then **blink** and **turn your head** when asked. Answer one question by clicking. — The exam should start, and answers should save WITHOUT showing whether you were right.
- [ ] 5.2 Wrong-face test: hold the other person's face photo (phone screen, brightness up) in front of the camera for about 10 seconds. No photo? Fallback: look fully away from the screen and cover the camera for about 15 seconds. — The exam should PAUSE and offer recovery. Show your own face again, tap **Blink to recover** and blink — the exam should continue and answers should work again.
- [ ] 5.3 Repeat step 5.2 until the exam says it is **flagged**. Try **Blink to recover** again. — Recovery should now be REFUSED. Switch to Window A: open the results, find your row, tap **Unlock** (you must type a reason). Back in Window B — the exam should continue. Window A should show a note that an unlock happened.
- [ ] 5.4 Answer the multi-select question (tick the answers) and TYPE an answer for the short question. — The short answer should show a “waiting for marking” label (it is marked later, not now).
- [ ] 5.5 Tap **Skip** on one question. — The question should stay skipped; you should NOT be able to answer it afterwards.
- [ ] 5.6 Hand gestures: tap **Continue** on the gesture panel (or Skip if you prefer clicks). Hold up **2 fingers** to answer one question, then show an **open palm** to move on. Then cover the camera for about 12 seconds. — The finger answer should save once; the palm should move you on; covering the camera should pause the exam, and blinking should recover it.
- [ ] 5.7 Cheat checks (30 seconds): try to COPY the question text (Ctrl+C), and press **Esc** to leave full screen. — Copying should be BLOCKED, and leaving full screen should pause the exam (not flag it).
- [ ] 5.8 Tap **Submit**. — You should see “Submitted — results will be released by your lecturer” with NO score shown yet.

## Phase 6 — Marking, results and Excel (lecturer, 10 min) ★

Window A only (peek at Window B where told).

- [ ] 6.1 Open the **Results** page for **Test - Exam**. — You should see one row per student with scores, pause counts, and a face-check timeline.
- [ ] 6.2 Open the **Question insights** section. — You should see per-question success rates and answer bars. Then click the student's paused/flagged row to expand it. — A short **incident video** should play with a reason and length shown. (A student with a clean exam would have no video — that is correct and private by design.)
- [ ] 6.3 Wait 1–2 minutes, then refresh. The typed short answer should change from “waiting” to a mark. Open it and tap **Change mark**: first try saving with NO mark and a 2-letter reason. — It should REFUSE without saving. Now pick a mark, type a proper reason, save. — The student's total should update immediately.
- [ ] 6.4 Tap **Release to students** and confirm. Switch to Window B. — You should now see the score with per-question answers, and BOTH windows should get a bell notification that opens the results.
- [ ] 6.5 Tap **Export Excel** and open the file in Excel / Sheets. — The file should be named like the quiz plus today's date, with Results, Answer Key and Distribution sheets, green/red answer cells, and a row for every student. Then open the class **Gradebook** and its export too. — Scores, averages and released/unreleased markers should all be there.

## Phase 7 — Quick checks (5 min) ★

Either window unless stated.

- [ ] 7.1 Tap the **language button** (EN/BM) on the login page and inside the app, then reload. — Everything should switch language and STAY switched. You should never see raw text like “nav.home”.
- [ ] 7.2 Open your **account menu** (top-right avatar) and tap the **theme button** a few times, then reload. — Light/dark mode should switch and stay switched; everything should stay readable.
- [ ] 7.3 In the account menu, upload a **profile photo**, then remove it. — The photo should change and then clear.
- [ ] 7.4 Phone check. Have your phone? Open the site on it, use the bottom tabs, open the account panel and the bell. No phone? Drag Window B narrow (about phone-width) instead. — Everything should fit with NO sideways scrolling.
- [ ] 7.5 Window B: paste a lecturer page address into the address bar (ask your lead for one). — You should be sent back to the student pages automatically.
- [ ] 7.6 Only if your lead asks: test the **Microsoft sign-in** button once, and the **Forgot password** email once. Never run these repeatedly.

## Phase 8 — Clean up (lecturer, 5 min)

- [ ] 8.1 Window A: **Close** both Test quizzes, then **Archive** the **Test** class. Window B: refresh. — The class and its quizzes should DISAPPEAR for the student. Window A: **Restore** the class — everything should come back. (Your lead will tell you whether to leave it restored or archived — write your choice in the sign-off below.)
- [ ] 8.2 Delete any throwaway test quizzes that nobody started. — They should disappear. Quizzes WITH student attempts can never be deleted — leave those alone.
- [ ] 8.3 Glance at the results pages once more. — Every flag, video and mark you see should match a step you did above. Anything you cannot explain is a bug — write it down.

## If something looks wrong

> Do not try to fix it. Just capture it: **step number** (for example 5.3),
> **what you expected**, **what actually happened**, and a **screenshot**
> (Windows key + Shift + S, then paste into a message to your lead). Add each
> problem to the sign-off sheet below.
