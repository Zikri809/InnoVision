# Terms used in this manual

| Term | Meaning |
| --- | --- |
| Class | A lecturer's group of students and its assigned quizzes. |
| Join code / QR | A way to enter a class. The lecturer shares the six-character code or displays its QR link. |
| Draft | A quiz the lecturer can edit; students cannot start it. |
| Live | A published quiz. Opening and closing times may still limit when a student can start. |
| Closed | A quiz that no longer accepts new attempts. Closing is one-way. |
| Practice quiz | A class quiz with repeat attempts and immediate feedback, or a separate personal quiz made by a student. The guide identifies which kind it means. |
| Assessment | A class quiz whose attempt, verification, score release, and possible time limit are controlled by the lecturer's settings. |
| Attempt | One student's run through a class quiz. A retake is a new attempt when the lecturer allows one. |
| Face enrollment | The student's one-time camera setup for verified assessments. |
| Pause | A temporary stop that asks the student to follow an on-screen recovery step. |
| Flagged | An attempt that needs lecturer review before the student can continue. |
| Face exemption | A lecturer decision to stop face checks for one student's attempt, with a recorded reason. |
| Reset | A lecturer action that permanently deletes an attempt's answers, progress, and integrity details so the student can start over. |
| Reveal / release results | The point when the lecturer makes assessment scores and answer breakdowns visible to students. |
| Shared personal quiz | A student's unlisted practice quiz opened by a share link. Recipients must sign in; the owner does not see who played. |
