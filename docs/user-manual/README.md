## Student quick start

1. [Create your account or sign in](student.md#create-an-account-or-sign-in).
2. [Join your lecturer's class](student.md#join-a-class).
3. [Find a class quiz](student.md#find-a-class-quiz).
4. If the assessment requires it, [set up your face](student.md#set-up-face-verification)
   and follow the start instructions.
5. [Answer and submit](student.md#take-and-submit-an-assessment).
6. [Check your result](student.md#see-your-results) once it is available.

## Lecturer quick start

1. [Create your lecturer account or sign in](lecturer.md#sign-in-as-a-lecturer).
2. [Create a class and share its join code](lecturer.md#create-a-class-and-invite-students).
3. [Create a quiz and add questions](lecturer.md#create-a-quiz).
4. [Check and publish the quiz](lecturer.md#publish-and-manage-a-quiz).
5. [Monitor attempts and release results](lecturer.md#review-attempts-and-help-students).

## Using the manual on a phone

Easy2U uses top navigation on a desktop and a bottom dock on a phone. Some
lecturer tools use sheets or compact lists on a phone. The guides label steps
**Desktop** and **Phone** wherever the action changes. Close the on-screen
keyboard if the bottom dock is temporarily hidden.

## Before you start

Use the account and class details supplied by your institution or lecturer.
Assessments that require face verification need a working camera, camera
permission, and a well-lit space. Some options, including Microsoft sign-in,
AI question generation, web topic search, and hand gestures, appear only when
your institution or lecturer enables them.
