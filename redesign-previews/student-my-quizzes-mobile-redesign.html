Implementation sketch — all inside max-sm: branches

Files touched: my-quizzes-client.tsx (mobile layout + sheet state machine), en.json/ms.json (4 new keys). No new primitives — the sheet is the existing ResponsiveModal, which already renders as a bottom sheet on mobile; the sheet bodies are plain Button/Input compositions.

Key decisions to sign off

  • Card = link to /play/student/{id} (or /edit when 0 questions) via the stretched-link pattern; the ⋯ button sits above it with z-index and aria-label="More actions for {title}" — no nested interactive elements.
  • Sheet state machine: null → "menu" → "share" | "delete"; back button returns to menu, scrim/drag/Esc dismiss. Replaces the two ResponsiveModals on mobile; desktop keeps the current dialogs.
  • Floating + = FAB above the dock: direction-aware hide (translate+fade on scroll-down >8px, return on scroll-up; always visible at top). 58×58px, 44px+ hit area, aria-label="Create quiz" — keeps the e2e create-flow name. Docks that already hide on scroll (this repo's pattern) compose cleanly with it.
  • Private badge removed — absence of the Shared chip is the signal. If lecturers-in-review disagree, it's a one-class revert.
  • Relative dates optional: Intl.RelativeTimeFormat for <7 days ("2d ago"), else "Sep 8". Costs one helper.
  • Error banner + aria-live region stay as-is (not shown in the mockup).
